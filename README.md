# model-LB-replication

Replication package for "Calibrating Point-Optimal Unit Root Tests for Level Breaks in Small Samples: Evidence from Real Exchange Rates" (Ricardo Gonçalves Silva).

**Status: version 3 in preparation.** The repository is being rebuilt to accompany the current version of the manuscript. Until version 3 is released, it contains no code.

Earlier versions of the package (v2.0.0 and v2.0.1) accompany an earlier draft of the paper. They remain available in the git tags `v2.0.0` and `v2.0.1` and on Zenodo, concept DOI [10.5281/zenodo.21229773](https://doi.org/10.5281/zenodo.21229773). Their numbers do not correspond to the current manuscript.
